# 코드 이름 검색과 설명 계획

검색창에서 지도에 없는 코드 이름도 찾는다. 첫 검색은 AI를 호출하지 않고 코드의 이름과 위치를 보여준다. 기존 지도나 저장된 설명이 연결되면 짧은 역할도 함께 보여준다.

사용자가 생성 버튼을 누르면 선택한 코드를 AI로 분석해 역할, 하는 일, 관련 코드의 구조와 구조도를 만든다. 결과와 근거를 저장해 다음 검색에서 다시 보여준다. 새로고침 시 관련 코드의 변경 여부를 확인하고 설명이 오래됐으면 표시한다. AI 호출은 사용자가 생성할 때만 한다.

동일한 이름이 여러 곳에 있으면 사용자가 대상을 구분할 수 있어야 한다. 코드 검색 범위, 분석에 포함한 파일과 근거, 알 수 없는 내용도 결과에서 구분한다.
